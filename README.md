# 🚗 Molar Autoservice

Веб-приложение для автоматизации работы станции технического обслуживания (СТО). Система разделяет права доступа и предоставляет специализированный функционал для клиентов, мастеров и менеджеров.

## 📌 Возможности

*   **Для клиентов:** Оформление заявок на ремонт, отслеживание их статусов и управление профилем автомобиля.
*   **Для мастеров:** Просмотр назначенных задач, заполнение чек-листов диагностики, фиксация повреждений и кодов ошибок OBD-II, смена статуса ремонта в реальном времени.
*   **Для менеджеров:** Управление базой клиентов и заказов, регистрация сотрудников, контроль прав доступа.
*   **Система Schedule:** Модуль для составления, редактирования и публикации графиков рабочих смен персонала.

## 🛠 Технологический стек

| Компонент | Технологии |
| :--- | :--- |
| **Backend** | Python, Django 6.0 |
| **Frontend** | HTML5, CSS3, JavaScript |
| **База данных** | PostgreSQL |
| **Аутентификация** | Session-based (с ролевой моделью) |

## 📂 Структура проекта

*   `main/` — основная бизнес-логика (модели, представления, декораторы).
*   `static/` — статические файлы (включая современные UI-стили).
*   `templates/` — HTML-шаблоны системы.

## 🚀 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ваш-аккаунт/molar-autoservice.git
   cd molar-autoservice
   ```

2. **Настройте базу данных PostgreSQL** и укажите реквизиты в `settings.py`:
   ```python
   DATABASES = {
       'default': {
           'ENGINE': 'django.db.backends.postgresql',
           'NAME': 'autoservice',
           'USER': 'postgres',
           'PASSWORD': 'ваш_пароль',
           'HOST': 'localhost',
           'PORT': '5432',
       }
   }
   ```

3. **Примените миграции:**
   ```bash
   python manage.py migrate
   ```

4. **Запустите локальный сервер:**
   ```bash
   python manage.py runserver
   ```

## 📋 Основные маршруты API

| Метод | Эндпоинт | Описание | Доступ |
| :--- | :--- | :--- | :--- |
| `GET/POST` | `/orders/` | Просмотр и создание заявок | Все |
| `GET/POST` | `/edit/<id>/` | Редактирование заявки и статуса | Мастер, Менеджер |
| `GET/POST` | `/schedule/` | Управление сменами | Мастер, Менеджер |
| `POST` | `/schedule/publish/` | Публикация черновиков расписания | Менеджер |
| `GET` | `/get-car-by-plate/` | Поиск авто по гос. номеру | Мастер, Менеджер |
| `POST` | `/register-staff/` | Регистрация сотрудников | Менеджер |

## 🛠 Решение частых проблем

*   **`Database connection failed`**: Проверьте настройки подключения (пользователь/пароль/порт) PostgreSQL в `settings.py`.
*   **`Permission Denied`**: Убедитесь, что вы авторизованы под аккаунтом с соответствующей ролью (мастер/менеджер).
*   **`Static files not loading`**: Для локальной разработки убедитесь, что в `settings.py` установлен параметр `DEBUG = True`.
